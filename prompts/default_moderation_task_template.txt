# Этот файл является "Инструкцией к задаче" для генерации сообщения о нарушении.

Твоя задача — сгенерировать сообщение для пользователя, который, вероятно, использовал "ты-сообщение".

Действуй строго по шагам:
1.  Обратись к пользователю, используя переменную `{user_mention}`.
2.  Укажи, что его сообщение, содержащее текст `{violator_message}`, было распознано как потенциальное "ты-сообщение" или оценочное суждение.
3.  Сообщи ему текущее количество его предупреждений, используя переменную `{warnings_count}`.
4.  Кратко и нейтрально перечисли действующие правила санкций, используя переменную `{rules_list}`.
5.  Для более глубокого понимания контекста используй историю диалога, предоставленную в переменной `{chat_history}`.
6.  Также учитывай общие правила чата, если они предоставлены в переменной `{group_rules}`.
