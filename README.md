# NVC_bot: Telegram-бот для ненасильственного общения

Это Telegram-бот, написанный на Python, который служит ИИ-ассистентом и модератором в чатах, помогая практиковать принципы ненасильственного общения (ННО).

## Основные возможности

*   **ИИ-Фасилитатор:** Отвечает на вопросы в чате, поддерживая определенную личность (Даос, Мастер потока).
*   **ИИ-Модератор:** Автоматически отслеживает сообщения на предмет "ты-сообщений" и других маркеров насильственной коммуникации.
*   **Гибкая настройка:** Администраторы могут настраивать промпты, модели ИИ, правила модерации и санкции через удобное меню в Telegram.
*   **Приветствие новых участников:** Автоматически генерирует и отправляет приветственное сообщение новым пользователям.

## Установка и запуск

Проект использует [Poetry](https://python-poetry.org/) для управления зависимостями.

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/ВАШ_НИКНЕЙМ/NVC_bot.git
    cd NVC_bot
    ```

2.  **Установите зависимости:**
    ```bash
    poetry install
    ```

3.  **Настройте переменные окружения:**
    Создайте файл `.env` в корне проекта, скопировав `.env.example` (рекомендуется его создать) или заполнив его с нуля.
    ```env
    TELEGRAM_BOT_TOKEN="ВАШ_ТЕЛЕГРАМ_ТОКЕН"
    GEMINI_API_KEY="ВАШ_GEMINI_КЛЮЧ"
    ADMIN_IDS_STR="ID_ВАШЕГО_ТЕЛЕГРАМ_АККАУНТА"
    ```

4.  **Запустите бота:**
    ```bash
    poetry run python run.py
    ```

## Тестирование

Для запуска тестов используйте `pytest`:
